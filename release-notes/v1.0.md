## Highlights
* First Android 11 build for the SM-T820 produced entirely on an **arm64 build host**
  (no Rosetta/x86 emulation).
* Boots to the home screen in ~40 s (≈2 min on first boot with GApps).
* Verified on device: Wi-Fi (2.4/5 GHz scan + connect), Bluetooth, speaker audio,
  display 1536×2048 with HWC composition, 21 sensors, battery/charging, Play Store +
  Google Play services (with MindTheGapps 11), installing apps from the Play Store.
* No system_server crashes, reboots or ANRs during a multi-hour soak (log watcher); the
  only crashes were in the wallpaper picker (see Known issues).

## Changes vs. a stock LineageOS 18.1 tree
* Arm64-host build fixes (29 projects) — see the build repo.
* **Removed**: Gallery2, `monkey`, ANT+ (`AntHalService`, `com.dsi.ant.antradio_library`).
* **RenderScript**: compiler tools not available on the host; `bcc`/`ld.mc` not shipped,
  `bcc_strip_attr` replaced by a pass-through, MediaCodec saturation filter stubbed.
* Tethering compiled with `--add-reads java.base=ALL-UNNAMED`.
* Debug-friendly: `ro.adb.secure=0`, `persist.sys.usb.config=adb`, `adb root`
  (Developer options → Rooted debugging).

## Known issues
* **UI jank**: 14–21 % janky frames in launcher/shade/Settings/Spotify. Qualcomm perf boosts
  never fire (`QTI PowerHAL: Failed to acquire lock`; `libqti-perfd.so` not shipped) and the
  kernel input boost is only 40 ms. Fixed in v2.
* Wallpaper picker → "My photos" crashes (no gallery app). Workaround: install any gallery.
* `/data` unencrypted; SELinux permissive (kernel cmdline); test-keys.
* RenderScript apps that compile scripts at runtime may fail.
* Apps are not dex-preopted in the image (first launches are slower until background dexopt).

## Upgrade / rollback
Clean install only (format data). Keep a full backup; rolling back = restoring the backup
from TWRP.
