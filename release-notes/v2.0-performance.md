# v2.0 — performance release (DRAFT — not released yet)

Scope and method: [OPTIMIZATION_PLAN.md](https://github.com/gauravsuman007/lineageos-arm64-host-build/blob/main/docs/OPTIMIZATION_PLAN.md).
Everything below must be built into the images — nothing applied by hand on the device.

## Planned changes
- [x] **Interaction / launch boosts** — replaced the non-functional QTI power HAL + perf
      service with the open-source AIDL power HAL (`power-libperfmgr`) and a msm8996
      `powerhint.json`:
      INTERACTION → little ≥1.04 GHz, big ≥1.25 GHz, top-app stune 30, GPU ≥315 MHz;
      LAUNCH (5 s) → max CPU, stune 50, GPU ≥402 MHz; EXPENSIVE_RENDERING → GPU ≥510 MHz.
      Port notes: the touch handler's idle node is `fb0/idle_notify` on this kernel
      (`hardware/google/pixel` patch); `vendor.powerhal.init=1` set on boot_completed;
      sepolicy labels the service `hal_power_default` (no denials). Verified from a
      flashed image.
- [x] **Kernel input boost** in `init.qcom.power.rc`: 500 ms at 1.32/1.56 GHz (was 40 ms at
      1.32 GHz), top-app stune 20, `blu_schedutil` up 0 µs / down 40 ms
      (in the device tree; measured janky frames ~16 % → ~10 %).
- [ ] **Kernel from source** in `boot.img` (awesometic v0.13 + GPMU acknowledgement fix +
      governor defaults), reproducibly built on the arm64 host.
- [x] **Dex-preopt** system apps (host `dex2oat` built natively for arm64; SystemUI,
      Settings, Trebuchet at `speed`). Boot to `boot_completed` in 35 s after the flash.
- [x] Removed the dead QTI perf service blob (crash-looped once its library was gone).
- [x] **Charging & performance** (Settings › Battery), service `vendor.chargehold`:
      charge limit with hysteresis (default stop 80 %, resume 75 %) via the Samsung
      `hmt_ta_charge` switch; pauses charging above a battery temperature (40 °C);
      optional plugged-in profile (input boost 1.59/2.0 GHz for 800 ms, GPU start level 4)
      that drops automatically when warm — **off by default** (no measurable jank gain,
      about +3 °C board temperature). Own SELinux domain, settings in
      `persist.sys.chghold.*`.
- [ ] Memory/I/O tuning (zram, lmkd, read-ahead) — only if measurements justify it.
- [ ] Gallery2 restored (fixes wallpaper "My photos" crash).
- [ ] Root-cause the empty-jar javac issue (monkeylib/ANT).
- [ ] SELinux policy for the new power HAL (towards enforcing).
